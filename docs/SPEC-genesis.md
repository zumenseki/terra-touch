# SPEC — terra-touch: 創世 (GENESIS)

terra-touch(実写地形×GPU水シム×指で変形)を土台にした**神ゲー**。
神=指で地形と水だけを操る。原始人を置くと自動で文明を築く。災害から守り見守る。

## 全体像
- **プレイヤーの力**: 掘る/盛る(体積保存)・雨・(将来)溶岩逸らし = 既存の変形/水ツールがそのまま神の力。
- **住民**: 直接命令しない。世界の状態に反応して自律的に定住・発展。
- **視点**: 文明を"見守る"。個体管理はしない → **村単位で抽象化**。
- **進行**: 無限サンドボックス+実績。ハードなゲームオーバー無し(村全滅→再興)。
- **舞台**: 実写名所20箇所 + (G4)生成島。

## モード
現 `geo.html`(創作トイ)は温存。ゲームは同アプリ内の**「🌱 創世モード」トグル**で起動
(エンジン=sim-gpu/描画/locations を共有)。sculpt ツールは神の力として継続。

## データ設計
```
World (既存GPU): state[bed, soil, water, wet]  1024²
Coarse field (2Hz 読戻し 128²): [height, water, wet]  … 村ロジックの世界センサ
Village {
  u, v            // 位置 0..1
  pop             // 人口 (連続値)
  food            // 食料ストック
  era             // 0=石器 1=農耕 2=集落 …
  buildings: []   // 種別と相対位置
  settled: bool
}
Band {  // 定住前のさまよう一団
  u, v, target?  // 適地へ hill-climb
}
Suitability(u,v) = flatness(demH勾配) × waterProximity(coarse) × vegetation(G1+)
```

## コアループ
種を置く → band が適地(平地×水近)へ移動 → 定住=Village 生成 →
suitability>閾値 なら pop 増 → 閾値超で建物追加 → era 進化 →
pop 過密+空き適地 で新 band 分岐 → 災害 → 神が地形/水で守る。

## マイルストーン別 受入条件
### G0 村基盤 (今回)
1. 「原始人を置く」で band を配置でき、**平地かつ低所(将来水近)へ自動移動して定住**する
2. 定住地で **pop が増え、閾値で小屋メッシュが建つ**のが見える
3. 村の周りに**代表の人(数体)が動く**(生きてる感)
4. GPU既定・スマホ可・NaN無・既存の変形/水品質を割らない・console err 0

### G1 植生・肥沃度
- 水/湿りで植生場が育ち乾くと枯れる。suitability に植生を反映。神の水やりで村が育つ。

### G2 村成長・時代
- pop→小屋/農地/家の段階的追加。era 2〜3段で見た目進化。過密→新村分岐。

### G3 災害・実績
- 洪水(既存水位上昇)+干ばつ(雨停止→枯れ)。神が堤防/水路で防ぐ。実績解除。

### G4 噴火(溶岩=第2流体)・津波・生成島・磨き・公開。

## 非目標(v1)
個体完全AI/戦争・敵対/直接命令/マルチ/複雑経済ツリー/セーブ共有/溶岩(G4まで)。

## 技術メモ
- 村ロジック=CPU 低頻度(〜2Hz)。世界センサ=GpuSim の coarse 読戻し(縮約128²)。
- 村/人/建物=three インスタンス。高さは当面 静的DEM 参照(sculpt 追従は後日)。
- 密度cap+LOD でスマホ負荷を抑える。
